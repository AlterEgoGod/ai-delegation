# ai-delegation

Переносимый модуль для Codex: Astra ставит задачи и принимает результат; Luna, Terra и Sol выполняют подходящие подзадачи.

[Установка из Git](99_Инструкции/INSTALL.md) · [Правила](99_Инструкции/RULES.md) · [Содержание](99_Инструкции/README.md)

Установка выполняется отдельно или через ai-rules. Используется фиксированный Git-коммит, без загрузки правил из сети при каждой задаче.
