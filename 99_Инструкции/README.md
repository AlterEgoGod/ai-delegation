# Модуль делегирования

## Состав

- `RULES.md` — короткая обязательная инструкция.
- `INSTALL.md` — установка, проверка, обновление и удаление.
- `01_Сценарии/delegation.md` — постановка подзадачи и выбор исполнителя.
- `01_Сценарии/verification.md` — приёмка результата и измерение расходов.
- `02_Конфигурация/config.toml` — Astra и ограничения субагентов.
- `02_Конфигурация/delegation-*-worker.toml` — три именованных исполнителя.
- `03_Установка/install.ps1` — оболочка для Windows PowerShell.
- `03_Установка/install.py` — установщик на Python 3.11+, без сторонних пакетов.
- `04_Проверки/test_install.py` — проверки сохранности настроек и повторной установки.

В рабочих папках есть `99_Архив`. Архивы не читаются как действующие инструкции. Технические каталоги `.codex/agents` сохраняют имена, требуемые Codex.

## Поддержка

Локальный Codex CLI и IDE с поддержкой `agents.default_subagent_model` и пользовательских агентов. При разработке использовался Codex CLI 0.154.0-alpha.6.2. Установщик проверяет файлы и Git-версию, но не выполняет платные вызовы моделей и не подтверждает доступность моделей на аккаунте. Для активации нужна новая сессия и доверенный проект.

Настройки интерфейса, параметры запуска, политики организации и ограничения среды могут переопределять настройки проекта. Обычный ChatGPT без доступа к файловой системе Codex не получает эти настройки от одного URL.
